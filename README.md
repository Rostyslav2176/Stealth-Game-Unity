# Silent Shadow

## Game Overview:
First person fast paced stealth game, where you interact with objects to distract enemies. Goal is to eliminate all the enemies as fast as you can.

Link to project: https://rostyslav2176.itch.io/silent-shadows

## How to Play:
WASD - Movement;
Mouse - Rotate;
Shift - Sprint;
Ctrl - Crouch;
Space - Jump;
E - Interact;
F - Stealth Takedown;

## How to run the application:
### Github Installation
  1. Make sure you have Unity 5 installed or are comfortable with version upgrading.
  2. Download Zip.
  3. Extract file to desired location
  4. Open extracted folder in Unity
